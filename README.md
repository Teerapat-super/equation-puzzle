# 🧩 Equation Puzzle: ภารกิจพิชิตสมการ

เกมต่อจิ๊กซอว์สำหรับฝึก **การแก้สมการเชิงเส้นตัวแปรเดียว** สำหรับการสอนชั้นมัธยมศึกษาปีที่ 1
แบ่งเป็น **6 ด้าน ด้านละ 5 ข้อ** (ด้านสุดท้ายเป็นแบบผสม) พร้อม **จับเวลาทุกข้อ** และ **กราฟพัฒนาการ** ของนักเรียนแต่ละคน
ผู้เล่นลากชิ้นส่วนการดำเนินการไปวาง **ทั้งสองข้างของสมการ** เพื่อเรียนรู้หลักความสมมูลของสมการ ไม่ใช่การ “ย้ายข้างเปลี่ยนเครื่องหมาย” แบบท่องจำ

▶️ **เล่นออนไลน์:** `https://<ชื่อผู้ใช้>.github.io/<ชื่อ-repo>/` (ใช้ได้หลังเปิด GitHub Pages ตามขั้นตอนด้านล่าง)

## ✨ จุดเด่น

- ไฟล์เดียว (`index.html`) เปิดเล่นได้ทันที ไม่ต้องติดตั้ง ไม่ต้องใช้อินเทอร์เน็ต ไม่มี Backend
- รองรับคอมพิวเตอร์ (ลากวางด้วยเมาส์) และมือถือ/แท็บเล็ต (แตะเลือก แล้วแตะช่องที่จะวาง)
- เลือกฝึกได้ทีละด้าน ด้านละ 5 ข้อ สุ่มโจทย์ใหม่ทุกรอบ (5 ข้อในรอบไม่ซ้ำกัน)
- ⏱ จับเวลาแต่ละข้อ (หยุดนับเมื่อสลับแท็บ/แอป) บันทึกเมื่อทำครบ 5 ข้อ พร้อมเทียบกับครั้งก่อน
- 📈 หน้าพัฒนาการ: กราฟเวลารวมและคะแนนต่อครั้ง แยกตามผู้เล่นและด้าน สรุปแนวโน้มอัตโนมัติ ตารางประวัติ
- ⬇ ส่งออก CSV (1 แถว = 1 ข้อ) เปิดใน Excel / Google Sheets ได้ทันที
- ตรวจสมการเชิงสัญลักษณ์ด้วยเศษส่วนแม่นยำ ไม่ใช้ `eval()` และไม่เทียบข้อความ
- แยกการตรวจ “ขั้นตอน” ออกจากการตรวจ “คำตอบสุดท้าย” (แทนค่ากลับในสมการตั้งต้น)
- มีคำใบ้ทีละขั้น ข้อความแนะนำเชิงบวก และสรุปคะแนนพร้อมเหรียญรางวัล

## 🎮 ด้านที่ฝึก (ด้านละ 5 ข้อ)

| ด้าน | เนื้อหา | ตัวอย่าง |
|---|---|---|
| 🌱 1 สมการสองขั้นตอน | `ax ± b = c`, `x/a ± b = c` | 4x − 7 = 21 |
| ⚡ 2 จำนวนลบ | สัมประสิทธิ์หรือคำตอบติดลบ | −3x + 7 = 19 |
| ⚖️ 3 ตัวแปรอยู่ทั้งสองข้าง | `ax + b = cx + d` | −2x + 5 = 3x − 10 |
| 🧩 4 สมการที่มีวงเล็บ | `k(x + m) = cx + d` | 3(x + 2) = x + 14 |
| 👑 5 วงเล็บทั้งสองข้าง | `a(x + m) = b(x + n)` | 4(x − 1) = 2(x + 3) |
| 🎲 6 แบบผสม | ด้าน 1 → 5 อย่างละ 1 ข้อ เรียงง่ายไปยาก | — |

**คะแนนต่อข้อ:** ไม่ใช้คำใบ้ 100 · ใช้คำใบ้ 80 · ลองผิดหักครั้งละ 5 แต่ไม่ต่ำกว่า 50
**เหรียญต่อรอบ (เต็ม 500):** 🥇 ≥ 450 · 🥈 ≥ 350 · 🥉 ต่ำกว่านั้น

## 📈 การบันทึกเวลาและพัฒนาการ (สำหรับครู)

- นักเรียนกรอก **ชื่อ / เลขที่** ก่อนเล่น (ควรใช้ชื่อเดิมทุกครั้ง) ระบบบันทึกเวลา คะแนน คำใบ้ และจำนวนครั้งที่ลองผิด **ของแต่ละข้อ** เมื่อทำครบ 5 ข้อ
- หน้า **📈 ดูพัฒนาการ** เลือกผู้เล่นและด้าน จะเห็น
  - กราฟเวลารวมต่อครั้ง (เส้นลดลง = เร็วขึ้น) และกราฟคะแนนต่อครั้ง (เส้นสูงขึ้น = ถูกต้องมากขึ้น)
  - สรุปแนวโน้มอัตโนมัติ: เทียบค่าเฉลี่ยช่วงแรกกับช่วงล่าสุด (สูงสุด 3 ครั้ง)
  - ตารางประวัติพร้อมเวลาแต่ละข้อ
- **ข้อมูลเก็บในเบราว์เซอร์ของเครื่องที่เล่นเท่านั้น** (localStorage) ไม่ได้ส่งขึ้นเซิร์ฟเวอร์ ครูกด **ส่งออก CSV** จากแต่ละเครื่องแล้วรวมในสเปรดชีตเพื่อวิเคราะห์ทั้งห้อง
- การล้างข้อมูลเบราว์เซอร์ การใช้โหมดไม่ระบุตัวตน หรือเปลี่ยนเครื่อง จะทำให้ไม่เห็นประวัติเดิม
- ข้อควรระวังในการตีความ: โจทย์สุ่มใหม่ทุกครั้ง ความยากแต่ละรอบต่างกันเล็กน้อย ควรดูแนวโน้มจากหลายครั้ง และพิจารณาเวลาควบคู่กับคะแนน
- รอบที่ออกกลางคัน (ยังไม่ครบ 5 ข้อ) จะไม่ถูกบันทึก

**คอลัมน์ใน CSV:** ผู้เล่น · ด้าน · ชื่อด้าน · ครั้งที่ · วันที่เวลา · ข้อที่ · ระดับโจทย์ · โจทย์ · เวลา (วินาที) · คะแนนข้อ · คำใบ้ · ลองผิด · เวลารวมของรอบ · คะแนนรวมของรอบ

## 📐 หลักการคณิตศาสตร์ที่รองรับ

- บวก/ลบจำนวน หรือพจน์ x เดียวกันทั้งสองข้าง
- คูณ/หารทั้งสองข้างด้วยจำนวนเดียวกัน (ไม่ยอมรับ ÷0 และ ×0)
- อธิบาย “การย้ายข้าง” ว่าเกิดจากการดำเนินการผกผันที่ทำทั้งสองข้าง
- การกระจายวงเล็บ และการรวมพจน์ที่คล้ายกัน
- แก้ได้หลายลำดับที่ถูกต้อง (ไม่บังคับวิธีเดียว)

**ขอบเขตที่ยังไม่รองรับ:** วงเล็บซ้อน, วงเล็บกับพจน์อื่นอยู่ข้างเดียวกัน (เช่น 2(x+1) + 3x = 17), เศษส่วนที่ตัวส่วนต่างกัน, สมการที่ไม่มีคำตอบหรือมีคำตอบมากมาย

## 🚀 วิธีนำขึ้น GitHub และเปิดให้เล่นออนไลน์ (ไม่ต้องใช้คำสั่ง git)

1. เข้า <https://github.com/new> → ตั้งชื่อ repository เช่น `equation-puzzle` → เลือก **Public** → กด **Create repository**
2. ในหน้า repo ที่สร้าง กดลิงก์ **uploading an existing file**
3. แตกไฟล์ zip แล้ว**ลากไฟล์และโฟลเดอร์ทั้งหมดในโฟลเดอร์ `equation-puzzle`** ไปวาง → กด **Commit changes**
   > หมายเหตุ: โฟลเดอร์ `.github` เป็นโฟลเดอร์ซ่อน ถ้าลากไม่ติดก็ข้ามได้ เกมยังทำงานปกติ (โฟลเดอร์นี้ใช้รันการทดสอบอัตโนมัติเท่านั้น)
4. ไปที่ **Settings → Pages** → ช่อง *Source* เลือก **Deploy from a branch** → Branch เลือก **main** และโฟลเดอร์ **/(root)** → กด **Save**
5. รอประมาณ 1–2 นาที แล้วรีเฟรชหน้า Settings → Pages จะเห็นลิงก์ `https://<ชื่อผู้ใช้>.github.io/equation-puzzle/` นำไปแชร์ให้นักเรียนได้เลย

### ถ้าใช้ git ในเครื่อง

```bash
cd equation-puzzle
git remote add origin https://github.com/<ชื่อผู้ใช้>/equation-puzzle.git
git branch -M main
git push -u origin main
```

(โฟลเดอร์นี้ commit ไว้ให้แล้ว จากนั้นเปิด Pages ตามขั้นตอนที่ 4)
